# SQL Sales Analysis

A beginner data-analysis project that loads a sales dataset into a
SQLite database and answers business questions using SQL.

## Questions answered
- Total revenue
- Revenue by category
- Top 5 customers by spend
- Monthly revenue trend
- Best-selling products by units
- Average order value
- Orders per customer
- Revenue by month and category

## Skills demonstrated
- SQL: `SELECT`, `WHERE`, `GROUP BY`, `ORDER BY`, `SUM`, `AVG`, `COUNT`, `LIMIT`
- Two-level grouping (`GROUP BY month, category`)
- Loading CSV data into a relational database with Python (`sqlite3`)
- Parameterized `INSERT` statements (safe against SQL injection)
